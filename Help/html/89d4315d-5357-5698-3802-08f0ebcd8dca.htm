      ClassLevelCascadeMode

      Sets the cascade behaviour in between rules in this validator. This overrides the default value set in DefaultClassLevelCascadeMode.

      If set to Continue then all rules in the class will execute regardless of failures.

      If set to Stop then execution of the validator will stop after any rule fails.

      Note that cascade behaviour within individual rules is controlled by RuleLevelCascadeMode.

      This cannot be set to the deprecated StopOnFirstFailure. StopOnFirstFailure. Attempting to do so it will actually result in Stop being used.
