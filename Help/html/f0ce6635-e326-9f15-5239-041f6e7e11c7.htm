      CascadeMode

      Gets a single CascadeMode mode value representing the default values of ClassLevelCascadeMode and RuleLevelCascadeMode., based on the same logic as used when setting this property as described below.

      Sets the values of ClassLevelCascadeMode and RuleLevelCascadeMode.

      If set to Continue or Stop, then both properties are set to that value.

      If set to the deprecated StopOnFirstFailure, then ClassLevelCascadeMode is set to Continue, and RuleLevelCascadeMode is set to Stop. This results in the same behaviour as before this property was deprecated.

      ClassLevelCascadeMode

      Sets the cascade behaviour in between rules in this validator. This overrides the default value set in DefaultClassLevelCascadeMode.

      If set to Continue then all rules in the class will execute regardless of failures.

      If set to Stop then execution of the validator will stop after any rule fails.

      Note that cascade behaviour within individual rules is controlled by RuleLevelCascadeMode.

      This cannot be set to the deprecated StopOnFirstFailure. StopOnFirstFailure. Attempting to do so it will actually result in Stop being used.
